# Build Agent hackathon guides

A static site for running a Build Agent hackathon: planning guide, interactive team planning template, prompting guide with a worked example (Workplace Issue Reporter), build and demo guide, and adding an agent or skill.

## Publish on GitHub Pages

1. Create a repository and upload the contents of this folder to the root (keep `.nojekyll`).
2. In the repository, go to **Settings > Pages**, set the source to your main branch and the `/ (root)` folder.
3. Your site appears at `https://<your-user>.github.io/<repo>/`. Put that link on the "Your guides" slide.

## Notes

- No build step: plain HTML, CSS and JavaScript.
- Checklists and the planning template save in each participant's browser (local storage) only. Nothing is sent anywhere.
- The site is client-generic. To reuse it, just publish it again; there's nothing to change per client.
